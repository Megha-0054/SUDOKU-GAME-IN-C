
# Sudoku Game in C

![Status](https://img.shields.io/badge/Status-Work%20in%20Progress-orange)

## About the Project

This is a console-based Sudoku game developed using the C programming language.

The project is currently under development. The aim is to create an interactive Sudoku game where users can fill empty cells and validate their moves according to standard Sudoku rules.

## Technologies Used

- C Programming Language
- GCC Compiler
- Visual Studio Code

## Features

- 9x9 Sudoku board
- Interactive user input
- Row validation
- Column validation
- 3x3 box validation
- Basic game completion check

## Current Status

🚧 Work in Progress

The basic structure and move-validation logic have been implemented. Additional features and improvements are still being developed.

## Future Improvements

- Multiple difficulty levels
- Random Sudoku puzzle generation
- Better user interface
- Solution checking
- Restart game option

## How to Run

Compile the program:

```bash
gcc sudoku.c -o sudoku
```

Run the game:

```bash
./sudoku
```
